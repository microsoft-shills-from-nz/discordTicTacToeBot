# Discord Tic Tac Toe bot
## About
This is a discord bot that will help you play Tic Tac Toe with random power ups!
## Setup
1. Clone Repo
Run this command:
```bash
git clone git@github.com:microsoft-shills-from-nz/discordTicTacToeBot.git
```
3. Install Dependencies
Run this command:
```bash
bun i
```
3. Get `.env.local` file contents
Get the bot token from discord and put it in the `DISCORD_TOKEN` field and the Turso token and url in the `TURSO_KEY` and `TURSO_URL` fields respectively.
5. Set up db
Make a table called `users` and give it these columns, then click create table.
